## Traceability rules

Every plan references requirement IDs and issue numbers. Every PR references an issue using `Closes #N` or `Refs #N`. Verification must record commands, results, and remaining gaps. Mark a requirement complete only after the corresponding issue is closed with passing checks.

## Definition of Done

- Issue with clear scope and acceptance criteria
- Phase plan and implementation summary
- Focused Conventional Commit and linked PR
- Automated tests and verification evidence
- Documentation updated where relevant
- Board status set to Done only after merge
