## Workflow per phase

1. Discuss the phase and record decisions.
2. Plan work in small, verifiable tasks.
3. Execute each task on a feature branch.
4. Verify test results and acceptance criteria.
5. Review the PR and documentation.
6. Ship via merge and close the linked issue.

Do not advance a phase solely because code was committed. Verification and acceptance are required.
