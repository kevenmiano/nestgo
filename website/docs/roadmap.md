# Roadmap

The [GitHub Project #2](https://github.com/users/kevenmiano/projects/2) and [repository roadmap](https://github.com/kevenmiano/nestgo/blob/main/.planning/ROADMAP.md) track work through GSD-inspired stages.

| Milestone | Focus | State |
| --- | --- | --- |
| M001 | Compiler/runtime stabilization | In progress |
| M002 | Modules, providers, controllers | Planned |
| M003 | Middleware, guards, pipes, interceptors | Planned |
| M004 | Config, caching, auth, OpenAPI | Planned |
| M005 | Events, queues, microservices, GraphQL | Planned |
| M006 | CLI, examples, benchmarks, releases | Planned |

**GSD workflow:** Discuss → Plan → Execute → Verify → Review → Ship.

:::info Documentation policy
Only features already implemented and tested are described as supported. Planned NestJS-inspired features remain in the roadmap until verified.
:::
