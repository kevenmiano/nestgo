# DTO transformers

NestGo compiles property decorators on DTO fields into typed JSON methods. Supported annotations include `@Expose`, `@Exclude`, `@Transform` with custom functions and `@Type` with static Go type checks.

See the [complete guide](https://github.com/kevenmiano/nestgo/blob/main/docs/DTO_TRANSFORMERS.md) for source examples, options, and limitations.
