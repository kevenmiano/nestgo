# Contributing

1. **Discuss** the proposal and Go-native design tradeoffs in an issue.
2. **Plan** with scope, acceptance criteria and test strategy.
3. **Execute** on a feature branch linked to the issue.
4. **Verify** with `go test ./...`, `go vet ./...`, `gofmt` and generated-code checks.
5. **Review** the PR and documentation for accuracy.
6. **Ship** only after green CI and update the milestone tracking.

See [CONTRIBUTING.md](https://github.com/kevenmiano/nestgo/blob/main/CONTRIBUTING.md) and [Project #2](https://github.com/users/kevenmiano/projects/2).
